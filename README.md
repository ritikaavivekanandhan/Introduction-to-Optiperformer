# Introduction-to-Optiperformer

### Aim
To download and install OptiPerformer software and run a sample fiber optic communication system simulation.

### Software Required

OptiPerformer is a photonic design automation tool developed by Optiwave. It is used to simulate optical communication systems and analyze optical power, Bit Error Rate (BER), Q factor, and eye diagrams.
The system includes:
- Optical transmitter
- Optical fiber channel
- Optical receiver
- Optical power meter
- BER analyzer
### Procedure

1. Download and install OptiPerformer from the Optiwave website.
2. Copy the Introduction_OptiPerformer.osp sample file to your computer.
3. Open the OptiPerformer software.
4. Select File → Open and load the sample file.
5. Study the transmitter, optical fiber, and receiver sections of the system.
6. Click the Start button to run the simulation.
7. Wait until the message “Calculation Finished!” appears.
8. Open the optical power meter and BER analyzer.
9. Observe the received optical power, eye diagram, Q factor, and BER.
10. Compare the output parameters for different fiber lengths.
